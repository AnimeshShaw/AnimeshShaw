### What I work on

- **Agentic AI security**: prompt-injection defenses at the tool-call boundary, intent-level controls for coding agents, runtime governance for multi-agent systems.
- **Post-quantum cryptography**: hybrid KEM/signature libraries, crypto-inventory and migration tooling aligned to NIST FIPS 203/204/205.
- **AI for security**: LLM-assisted malware analysis, AI-augmented SAST/DAST, benchmarks for the security of LLM-generated code.
- **Teaching & mentoring**: open curricula on threat modeling, secure code review and AppSec that anyone can run.
